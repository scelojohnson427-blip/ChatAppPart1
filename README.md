## Project Description

This project is a Java-based **Registration and Login System** developed as part of Part 1 of the ChatApp project.

The system allows a user to register an account by entering the required information and then use their registered details to log in. The project demonstrates basic Java programming concepts, input validation, conditional statements, methods, and the use of classes.

The project was developed and tested using **NetBeans**.

---

## Features

The Registration and Login System includes the following features:

- User registration.
- Username validation.
- Password validation.
- Storing registered user details.
- User login.
- Checking whether the login details are correct.
- Displaying appropriate messages for successful or unsuccessful registration.
- Displaying appropriate messages for successful or unsuccessful login.
- Java source code organised into classes and methods.

## How to Run the Project

### Step 1: Download or Clone the Repository

Clone or download this repository from GitHub:

**GitHub Repository:**
[https://github.com/scelojohnson427-blip/ChatAppPart1](https://github.com/scelojohnson427-blip/ChatAppPart1)

### Step 2: Open the Project in NetBeans

1. Open **NetBeans**.
2. Select **File**.
3. Select **Open Project**.
4. Locate the downloaded `ChatAppPart1` project folder.
5. Select the project and click **Open Project**.

### Step 3: Run the Project

1. Locate the main Java class in the project.
2. Right-click the main class.
3. Select **Run File** or run the project using the **Run Project** button.
4. Follow the instructions displayed by the program.

The project can be run using a Java Development Kit (JDK) installed on the computer. Java documentation provides the official technical documentation for Java SE and the JDK.
